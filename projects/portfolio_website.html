About

This page is all about this current portfolio website, built with simplicity and minimal dependencies requirements in mind.

I had a previous portfolio website that looked very similar to this one, built with SolidStart / SolidJS, Tailwind, and also TypeScript. However, after updating the project it broke a lot of the code due to the dependencies and other factors being out of date, so I wanted to build a new website with simpler technologies and as minimal dependencies as possible to avoid this issue in the future.

Chosen Tech Stack

This website development followed my initial work of Page Writer, which also used a vanilla JavaScript, HTML, and SCSS for its frontend. Lots of elements regarding structure and styling are based on what I did for my first web project.

For this website, I opted for vanilla JavaScript as opposed to a frontend framework like SolidJS, and used a different styling language in SCSS. These were chosen for both simplicity but also for building up my skills with vanilla (or similar) web technologies that I didn't quite learn in past projects.
